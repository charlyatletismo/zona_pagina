# AGENTS.md — Frontend (`src/react-app`)

Read the root [AGENTS.md](../../AGENTS.md) first. The full pattern guide is in
[docs/10-frontend.md](../../docs/10-frontend.md), and the page catalogue is in
[docs/11-features-and-views.md](../../docs/11-features-and-views.md).

## Stack

React 19, TanStack Router (file-based, `autoCodeSplitting`), TanStack Form, TanStack Table,
shadcn/ui (new-york style, Radix), Tailwind CSS v4, lucide-react icons, zod.
Path aliases: `@/` → `src/react-app/`, `@shared/` → `src/shared/`.

## Routes

- File-based, in `routes/`. `$param` gives dynamic segments, and dots are nested paths, e.g.
  `sportingEvents/$eventId.transactions.create.tsx` → `/sportingEvents/$eventId/transactions/create`.
- `routeTree.gen.ts` is regenerated by the Vite plugin. Never edit it.
- Every route declares a guard in `beforeLoad`:
  - `authCheck([ORGANIZER_ROLE, ...], mustNotBeBanned?)` (`lib/authCheck.ts`) redirects to
    `/login`, `/unauthorized`, `/settings/profile` (incomplete profile) or `/` (banned).
    `admin` always passes.
  - `unprotectedCheck()` (`lib/beforeLoadGenericCheck.ts`) is for public pages. It only applies
    the incomplete-profile redirect.
- Data loading happens in `loader`, using
  `getAuthenticatedThrow<z.infer<typeof S>>('/api/...', S)` from `lib/apiCalls.ts`.
  A 401/403 throws a redirect. Any other status is returned as `{status, body}`, so check
  `res.status` in the component. Set `staleTime` (5 min for lists; `0` for edit forms).
- Components read loader data with `Route.useLoaderData()`.

## Mutations

- `postAuthenticated(url, body, navigate?)` returns `{status, body: {data?, message?}}`.
  Show `getMessage(body.message)`, which picks the `es`/`en` text by `USER_LANGUAGE`.
- `postAuthenticatedFile(url, formData)` is for uploads (field name `file`).
- House style after a successful mutation: `window.location.reload()` or
  `navigate({ to, reloadDocument: true })`. There is no client query cache to invalidate.
- Banners: red `bg-red-500/10 text-red-600` with an `AlertCircle` icon, green for success. They
  auto-clear with `setTimeout`.

## Forms

- `const form = useAppForm({ defaultValues, validators: { onBlur: Schema }, onSubmit })`
  (`lib/genForm.ts`).
- Fields: `<form.AppField name="x">{(field) => <field.Input .../>}</form.AppField>`. Registered
  field components are Input, Textarea, Switch, DatePicker, DateTimePicker, SelectCustom,
  ComboBoxIdName, PhoneInput, CuitInput, plus Select/Command/Popover primitives.
- Error display: `className={!field.state.meta.isValid ? 'border-destructive' : ''}` plus a
  `* {errors[0].message}` line underneath. Validation messages come from the Spanish zod messages
  in `src/shared/types.ts`.
- Submit button: disabled when `!canSubmit || isPristine || isSubmitting`. Also add a Reset button.
  Wrap forms in `FormBox` (title, back link, `error` prop).

## Tables

TanStack Table with `createColumnHelper`, sortable headers (ArrowUp/ArrowDown), global fuzzy search
via `customFilterFn` (`lib/utils.ts`), `PaginationButtons` (page size 10), optional row-selection
checkboxes, and single-column grouping (`grouping.slice(-1)`). Copy an existing table, e.g.
`routes/users/index.tsx` or `routes/sportingEvents/$eventId.allRegistrations.tsx`.

## Session state

The session lives in `localStorage` only, written by `setUserInfo()` and cleared by `clearUserInfo()`
in `lib/utils.ts`:
`JWT_TOKEN, USER_ROLE, USER_ID, USER_NAME, USER_LANGUAGE, REQUIRE_PROFILE_UPDATE, ADMIN_MODE,
BANNED, BAN_REASON, PREVIEW_FEATURES`.
Components read `localStorage.getItem('USER_ROLE')` directly to show or hide UI. This is cosmetic;
the API enforces the real permissions.

## Caching

`lib/queryCache.ts` is a module-level, 5-minute cache for training teams (`getTrainingTeamsData`)
and managers (`getManagersData`). Reuse it instead of refetching those lists.

## Styling

- Tailwind v4 tokens are in `index.css`. Primary is orange `#fa4d25` (dark: `#ff6b4a`), and dark
  mode is class-based.
- Custom animations: `animate-tremor`, `animate-wiggle`, `animate-outer-shine`,
  `animate-badge-color-cycle`.
- Use semantic tokens (`bg-primary/5`, `text-muted-foreground`) so dark mode keeps working.
- Add shadcn primitives with `npx shadcn@latest add <name>` (config in `components.json`).
- UI text is **Spanish** (voseo). Event images are served from
  `https://imagedelivery.net/<account-hash>/<photo_id>/public`.
